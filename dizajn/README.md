# Векторски знакови извучени из дизајна табли

Извучено из `Ljubicina.pdf` (дизајн шумских табли). Оба фајла су чист вектор —
слова су претворена у путање, па не траже фонт.

- `znak-ljubicina-staza.svg` — натпис „LJUBICINA STAZA“ са срцем и листом.
  Иста датотека стоји и у `src/images/znak.svg` и користи се у заглављу сајта.
  Боје се задају CSS промењивама: `--znak-ime`, `--znak-staza`, `--znak-srce`.
- `logo-drvo.svg` — дрво у кругу, 290 путања, 213 KB. **Не користи се на сајту**
  јер је иста слика као оптимизован `webp` око 8 KB. Стоји овде за штампу и за
  случај да дизајнеру затреба вектор.

Фонт натписа на таблама је **Nexa Rust Slab Black** (у PDF-у уграђен као подскуп).
Сајт за наслове користи Roboto Slab, који му је најближи бесплатан парњак.
